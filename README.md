# GALO — Atlético Mineiro | AV2

Versão com o elenco profissional atualizado para novembro de 2026, usando como referência as páginas/listas oficiais do Atlético consultadas na atualização.

### Funcionalidades
- Elenco atual separado por posição;
- filtro de goleiros, zagueiros, laterais, meio-campistas e atacantes;
- escalação interativa com até 11 jogadores;
- adicionar/remover jogadores;
- formulário e validação;
- arrays, funções e DOM;
- feedback visual;
- localStorage;
- Bootstrap e responsividade.

Abra `index.html` no navegador.

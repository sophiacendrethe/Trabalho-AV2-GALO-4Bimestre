# GALO — Projeto Web

Tema: Clube Atlético Mineiro

Projeto desenvolvido para atender aos requisitos descritos no enunciado da AV1 e AV2:
- HTML semântico;
- CSS e identidade visual própria;
- Bootstrap 5;
- layout responsivo;
- interação JavaScript;
- formulário com validação;
- funções;
- array para dados;
- manipulação dinâmica do DOM;
- feedback visual;
- armazenamento temporário das mensagens com localStorage.

## Como executar
Abra o arquivo `index.html` no navegador.

## Estrutura
- index.html
- css/style.css
- js/script.js

Observação: o projeto usa Bootstrap e Google Fonts por CDN, portanto esses recursos são carregados pela internet.
